# Share Location (Fail Chat App, Vibe Coded)

Experimental chat app with live-location sharing: a Go backend (HTTP + WebSocket), a SolidJS web client, and an Android (Jetpack Compose) app. Built by prompting an AI agent; unfinished.

## Status / lessons
- Evaluation: feature requirements were left unfinished before the agent was told to code.
- Backend and web client implement the flow (login, conversations, messages, live location). The Android app is still the default Compose template (`MainActivity` + theme only); it does not talk to the backend yet.

## Tech stack
- Backend: Go 1.24, Fiber, WebSocket, Postgres (pgx), Redis pub/sub, logrus, YAML config
- Web: SolidJS, Vite, TypeScript
- Android: Kotlin, Jetpack Compose (Material 3), minSdk 28, package `com.fakhry.serlok`

## Layout
- `backend/` - API server (`cmd/server`, `internal/`, `config/`, `scripts/init.sql`, `docs/` with OpenAPI/AsyncAPI and architecture notes)
- `web/` - SolidJS client
- `android/` - Android app
- `untitled/` - scratch notes and sample location data
- `AGENTS.md` - repo conventions for coding agents

## Run
Backend (in-memory by default, no DB/Redis needed):
```bash
cd backend
go test ./...
go run ./cmd/server
```
Backend with Postgres + Redis (+ pgAdmin) via Docker Compose; API on `:8080`:
```bash
cd backend
cp .env.example .env
docker compose up --build
```
Web (dev server on `http://localhost:5173`, proxies `/v1/*` and `/ws` to `localhost:8080`):
```bash
cd web
npm install
npm run dev      # npm run build for a production bundle
```
Android:
```bash
cd android
./gradlew assembleDebug
./gradlew test
```

## Configuration (names only)
- `backend/.env` (template: `backend/.env.example`): `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`, `DB_URL`, `REDIS_URL`, `LOG_LEVEL`, `LOG_JSON`, `PGADMIN_EMAIL`, `PGADMIN_PASSWORD`
- Backend also reads `APP_ENV` and YAML under `backend/config/`; env vars override YAML.
- Web (optional): `VITE_API_BASE`, `VITE_WS_URL`
- Android: `android/local.properties` holds `sdk.dir` (generated by Android Studio, not committed)
